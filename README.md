# Real-World Data Project – Retail Sales Analysis

This project performs end-to-end analysis of a practice retail sales dataset.

## Analysis
- Dataset inspection and data quality checks
- Statistical summaries
- Monthly sales trend
- Sales by product category
- Sales by region
- Payment method analysis
- Quantity vs sales relationship
- Correlation analysis
- Visualizations and conclusions

## Important note
The CSV is a practice retail dataset generated for this learning project. It is not claimed to be company-provided or confidential real-world data.

## Files
- `retail_sales_analysis.ipynb`
- `retail_sales_dataset.csv`
- `README.md`
- `requirements.txt`

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter
